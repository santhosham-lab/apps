ENGINEERING REFERENCE

Formula library

A concise reference for the first implemented engineering calculator.

FLUID MECHANICS · RECIPROCATING PUMPSI UNITS

Theoretical discharge

Qth = A L N60

For a single-acting pump, where A is piston area (m²), L is stroke length (m) and N is speed (rpm).

A = πD² / 4

Double-acting pump

Qth = (2A − a) L N / 60

Here a is piston-rod cross-sectional area. If rod diameter is not supplied, the simplified approximation 2ALN/60 may be used and must be labelled as such.

PUMP PERFORMANCESI UNITS

Volumetric efficiency

ηv = QactualQth × 100%

Water power

Pw = ρ g Qactual H

Overall efficiency

ηo = (Pw / Pin) × 100%

Input power must be the shaft power supplied to the pump for this overall-efficiency calculation.

FLUID MECHANICS · CENTRIFUGAL PUMPSI UNITS

Water power

Pw = ρ g Q H

Q is the operating discharge (m³/s), H is manometric head (m), ρ is fluid density (kg/m³) and g is gravitational acceleration (m/s²).

Overall efficiency

ηo = (Pw / Pin) × 100%

Impeller tip speed

u = π D N / 60

D is impeller diameter in metres and N is rotational speed in rpm.

Metric specific speed

Ns = N √Q / H3/4

This convention uses N in rpm, Q in m³/s and H in metres. Specific-speed conventions vary; compare values only when the same convention is used.

Dimensionless coefficients

ψ = gH / u²
φ = Q / (nD³)

Here n is rotational speed in revolutions per second. These coefficients are useful for comparing dynamically similar operating points when definitions and units are consistent.

PROJECT NOTES

About MECHCALC

A free-first, browser-based Mechanical Engineering calculation platform.

Design principles

  • Transparent equations and unit handling.
  • Deterministic calculations rather than AI-generated arithmetic.
  • No mandatory account for core tools.
  • Progressive coverage of GATE Mechanical Engineering subjects.
  • Local-first operation wherever practical.

Important limitations

  • This is an early release with one engineering calculator.
  • Professional design checks, code compliance and safety factors are not yet implemented.
  • AI question interpretation and image/PDF extraction are not active yet.
  • Validate all results independently before using them in real equipment design or safety-critical work.
